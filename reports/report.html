Method. A black-box finding requires a hidden request to execute on a different client connection than the attacker's, after the attacker's connection has closed, reproduced across trials, with a clean negative control. This is the response-queue-poisoning mechanism, so the same probe travels to a remote target.

Scope. The instrumented differential runs only against the local range, where both hops are in-process. It covers ambiguity families a remote target cannot confirm without timing noise (bare-LF, chunk-size whitespace, chunk extensions, header-name whitespace, ...). It is labelled separately and never reported as a remote finding.

Local test range only. All listeners bind 127.0.0.1. Dialect presets are behavioural approximations, not copies of vendor code.
